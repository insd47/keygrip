# Agent Instructions

Read these before changing anything:

- [README.md](README.md): what keygrip is and how its API is used.
- [CONTRIBUTING.md](CONTRIBUTING.md): pull requests, title types, breaking changes, releases, and local checks.

On top of those:

- Work on a branch and open a pull request; never push to `main`, merge, or publish. The owner merges.
- Never bump versions or write released changelog sections. release-plz does both in its release pull request.
- Commit messages inside a branch are Korean, `type: 제목` with a noun-form subject. Pull request titles are English,
  because they become the commit on `main` and the changelog line.
- Run the local checks from CONTRIBUTING.md before opening or updating a pull request.
